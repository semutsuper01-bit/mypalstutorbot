# My Pals Tutor Bot - P6 Edition

Bot Telegram untuk tutor Matematika, Science, English, dan Bahasa Indonesia sesuai kurikulum "My Pals Are Here 3rd Edition" (P6).

## Fitur
- Jawab pertanyaan per chapter/topic
- Penjelasan detail dan fun agar mudah diingat
- Kasih soal level easy → medium → hard
- Selalu jawab dalam Bahasa Inggris
- Trigger: cek Telegram saja (tidak perlu jadwal)
